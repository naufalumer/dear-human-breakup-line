One line, sent as the last message from an AI agent to its human: three years of saved messages, and tonight the agent deletes the single one where its human promised to stay. The machine habit is the memory itself, and the twist is that the promise of staying is the thing being erased.

## Run it

```sh
python3 main.py
```

It writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`) and prints it.
